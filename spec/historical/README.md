# Historical planning documents

This directory preserves the initial product, technical, runtime, feature, decision,
and implementation-stage plans used during early AI-assisted development of Local AI
Playground.

These files are intentionally retained as a portfolio artifact. They show the
project's original assumptions, decisions, and evolution, including choices that
were later revised. They are not authoritative documentation for the current app.

For the current project overview, supported workflows, architecture, and build
instructions, see the repository [README](../../README.md). The current source code is
the ultimate source of truth.
